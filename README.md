# Lotto Number Generator

A simple web application that generates 6 unique random numbers between 1 and 45 for the lottery.

## Features

- Generates 6 unique random numbers.
- Sorts the numbers numerically.
- Color-coded balls based on the number range (1-10 yellow, 11-20 blue, 21-30 red, 31-40 purple, 41-45 green).
- Clean and modern user interface.

## How to use

1. Open `index.html` in your web browser.
2. Click the "Generate Numbers" button to get a new set of lottery numbers.
