
# Lotto Number Generator

## Overview

This project is a simple web application that generates random lottery numbers. The user can click a button to generate a new set of numbers.

## Current Plan

1.  **Create `index.html`**: Create the basic HTML structure for the lottery number generator.
2.  **Create `style.css`**: Style the page to be visually appealing.
3.  **Create `main.js`**: Add the JavaScript logic to generate and display the lottery numbers.
